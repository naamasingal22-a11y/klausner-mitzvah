## מה יש באתר
- **מפת המסע**: כל פעילות של השנה היא תחנה. אחרי מפגש עושים צ׳ק־אין, מקבלים חותמת וכותבים רפלקציה, ומוסיפים את הדמות מהקהילה לאלבום.
- **אתגרים** בארבעה צירים: זהות, חברה, קהילה, ידע ומסורת.
- **רימון של 613 גרעינים**, עם שלבים, תגים־מדבקות ואתגר שבועי.
- **ארון הספרים**: מאגר טעמי המקרא (עם דוגמאות אמיתיות מהתורה), זכוכית מגדלת לטעמים, מפת הסידור, העלייה לתורה, מדריך לגבאי/ת הצעיר/ה, מילון ובונה דבר תורה.
- **הפרשה שלי**: חישוב התאריך העברי, השבת והפרשה (לפי Hebcal), וקריאה עם טעמים מספריא, כולל מקליט לאימון.
- **משחקים**: טעם־מטרה, מפסיק או משרת, שרשרת טעמים, סדר בתפילה, חידון מושגים.
- **אזור הורים**: עקרונות, אחראים, סטטוסים ומשימות פתוחות.
