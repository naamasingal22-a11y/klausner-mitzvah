# העולם של יותם · בונים בר מצווה

גרסה אישית של אתר המסע לבר מצווה – מתנה ליותם, בעיצוב של עולם בלוקים.
האתר עומד בפני עצמו: אין בו תוכן של קהילת קלוזנר, וההתקדמות נשמרת רק בדפדפן של יותם.

## איך משנים
| מה | קובץ |
|---|---|
| ההקדשה, החתימה והשם | `assets/js/data/gift.js` |
| תחנות המסע (אבני הדרך) | `assets/js/data/program.js` |
| אתגרים, תגים ודרגות | `assets/js/data/quests.js` |
| סידור, עלייה לתורה, מילון | `assets/js/data/siddur.js` |
| צבעים ועיצוב | `assets/css/styles.css` (המשתנים בראש הקובץ, ושכבת העיצוב בסוף) |

## איך מעלים לאוויר
התיקייה הזו (`yotam/`) מועלית כמו שהיא ל-Netlify – אין שלב בנייה.
